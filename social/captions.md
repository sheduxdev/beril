## English

**Cover text:** Beril: scan the app you own, prove the bug, write the report.

**Caption**

Beril is a local-first, open source cybersecurity skill. It gives agents like Claude, Codex, Gemini, Cursor and Copilot a source-backed security workflow.

Two working lines:
Defense: scans an app, repo, APK/JAR, MCP config or Minecraft plugin you own. Output is a ranked fix list.
Attack: hunts bugs in open source behind an ownership gate, a networkless sandbox and maintainer reports. It does not build weaponized exploits.

Every finding carries severity, confidence, evidence, impact, a fix and what was not tested.

What it scans: web headers, CSP, cookies, CORS, TLS, SPF/DKIM/DMARC, secrets in git history, dependencies (KEV, EPSS, CVSS), MCP configs, vibe-coded apps, APK/IPA/EXE/ELF/JAR, Terraform, Kubernetes, Docker, SBOM.

Included: 65 tests, 10 practice labs, a 25-week training plan, reports for 4 readers (engineer, bug bounty, SMB, maintainer).

No telemetry, no uploads. Only test targets you own.

GitHub: sheduxdev/beril (MIT)
