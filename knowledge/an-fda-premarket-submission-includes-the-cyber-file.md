# An FDA premarket submission includes the cyber file

## Claim

The cyber device submission needs a threat model, a security risk file and a postmarket plan. A missing file delays the review.

## Test

Read the file list. Check the threat model and the plan. Map one control to one risk.

## Proof

A risk to control trace in the file.

## Failure modes

A small change can be a letter to file. A predicate device can set the bar.
