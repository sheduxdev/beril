# Docs are for the next decision

## Claim

A README explains why and how to run. An ADR records a decision. A runbook explains the failure.

## Test

Read the docs as a new hire. Can you run and debug it?

## Proof

A new hire completes the task without asking.

## Failure modes

A stale doc is worse than none if it is trusted.
