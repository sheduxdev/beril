# NIS2 scope is a sector and a size test

## Claim

The directive covers listed sectors above a size threshold and their suppliers. A small vendor can be in scope through a large customer.

## Test

Check the sector and the size. Check the customer contracts for security terms. Record the scope decision.

## Proof

A scope note with the sector, the size and the contract clause.

## Failure modes

A member state can widen the scope. A supplier clause can be separate from NIS2.
