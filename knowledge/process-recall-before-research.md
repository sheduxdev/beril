# Recall before searching

## Claim

Repeated research is waste. Check the knowledge index first, then refresh only a stale or low-confidence card.

## Test

Run recall with the target and class. If the decision is USE, answer from the card and test it. If REFRESH, verify one claim. If RESEARCH, collect.

## Proof

A card id and its proof, or a deliberate gap.

## Failure modes

A card can be stale. Check the date and the source before trusting it.
