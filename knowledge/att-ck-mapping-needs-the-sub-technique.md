# ATT&CK mapping needs the sub technique

## Claim

A parent technique hides the mechanism. The sub technique and the procedure text are what a detection can use.

## Test

Read the procedure. Pick the sub technique that matches the command. Write the procedure in one sentence.

## Proof

A sub technique ID with the observed command.

## Failure modes

A behavior can fit two sub techniques. A tool can implement several.
