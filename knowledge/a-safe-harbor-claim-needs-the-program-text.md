# A safe harbor claim needs the program text

## Claim

A safe harbor is a published promise with conditions. A blog post about the law is not the program terms.

## Test

Find the program policy. Read the conditions, the disclosure window and the excluded classes. Match your test to them.

## Proof

A quoted clause and a test plan inside it.

## Failure modes

A country law can add protection. A program can withdraw the promise later.
