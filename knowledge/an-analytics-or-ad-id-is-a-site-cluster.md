# An analytics or ad ID is a site cluster

## Claim

A shared tracking ID links sites under one account, often across brands and acquisitions.

## Test

Read the page source for the ID. Search the exact ID. Compare the owner and the certificate.

## Proof

A second site with the same ID and a corporate link.

## Failure modes

An agency can share one ID across clients. A tag manager can inject the ID later.
