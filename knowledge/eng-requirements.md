# Requirements are a decision, not a transcript

## Claim

A requirement names the user, the job, the constraint and the acceptance test. A feature list is not a requirement.

## Test

Write one sentence with actor, action and outcome. List what is out of scope. Ask what would make it fail.

## Proof

A builder and a reviewer can agree on the acceptance test before code.

## Failure modes

A requirement that cannot fail is a slogan.
