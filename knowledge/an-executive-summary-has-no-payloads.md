# An executive summary has no payloads

## Claim

A decision maker needs the risk, the cost and the decision. The request pair belongs in the technical section.

## Test

Read the summary alone. Name the decision it asks for. Move every payload to the appendix.

## Proof

A one page summary with a decision and a date.

## Failure modes

A technical reader still needs the detail. A summary without a decision is a table of contents.
