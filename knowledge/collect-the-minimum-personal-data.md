# Collect the minimum personal data

## Claim

Every extra field in a scan or a dossier is another data set to protect. A user list with emails needs a purpose and a deletion date.

## Test

List the personal fields collected. Name the purpose and the retention for each. Remove the fields with no purpose.

## Proof

A data table with purpose and deletion per field.

## Failure modes

A legal duty can justify a field. A hash can still be personal data.
