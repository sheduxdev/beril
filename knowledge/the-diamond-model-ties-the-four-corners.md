# The diamond model ties the four corners

## Claim

Adversary, capability, infrastructure and victim are linked. A missing corner is a collection task, not a conclusion.

## Test

Fill the four corners from the evidence. Mark the empty ones. Name the pivot that would fill each.

## Proof

A diamond with sources per corner and explicit gaps.

## Failure modes

A single log source fills one corner. A false pivot can invent a link.
