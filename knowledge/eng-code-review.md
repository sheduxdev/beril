# Review the change, not the author

## Claim

A review checks the problem, the smallest change, the failure modes, the tests and the rollback.

## Test

Read the description. Read the diff. Ask one question per risk. Approve only what you understand.

## Proof

A review comment that changes a decision or confirms it.

## Failure modes

Style comments without a reason are noise.
