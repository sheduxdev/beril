# An incentive shapes the local optimum

## Claim

A team optimizes what it is measured on. A deploy count can beat reliability.

## Test

List the top metric per team. Find a behavior it discourages.

## Proof

A metric pair that balances speed and stability.

## Failure modes

A single metric is gamed. A metric with no owner is ignored.
