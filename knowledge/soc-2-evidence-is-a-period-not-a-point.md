# SOC 2 evidence is a period, not a point

## Claim

A control that works on audit day is not a control. The evidence covers the whole observation window.

## Test

Pick one control. Read the samples across the period. Check the exceptions and the remediation.

## Proof

A sample set across the window with an exception log.

## Failure modes

A small sample can miss a gap. A compensating control can cover it.
