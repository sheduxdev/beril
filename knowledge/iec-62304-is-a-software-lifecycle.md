# IEC 62304 is a software lifecycle

## Claim

The standard requires a software safety class, a development plan and a risk file. The evidence is the process.

## Test

Read the class and the plan. Check the risk file and the trace. Find a requirement without a test.

## Proof

A requirement to test trace for one sample.

## Failure modes

A legacy device can have a gap. A class A device has less.
