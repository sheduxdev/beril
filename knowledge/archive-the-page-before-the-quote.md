# Archive the page before the quote

## Claim

A live page can change or vanish before the report. An archive URL and a capture time keep the quote checkable.

## Test

Save the page to an archive. Copy the archive URL and the time into the note. Quote from the archive.

## Proof

An archive URL with the capture time.

## Failure modes

An archive can miss a script page. A private page can refuse the crawler.
