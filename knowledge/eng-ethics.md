# Engineering judgment includes who pays

## Claim

A system can be correct and harmful. Name the user, the excluded user and the failure cost.

## Test

Write the harm model. Check the default and the edge case.

## Proof

A design with a stated harm and a mitigation.

## Failure modes

A privacy policy is not a design.
