# Ransomware triage is scope, encryption and backups

## Claim

The note names a family, but the real questions are which hosts, which accounts, and whether backups are intact.

## Test

Collect the note and extension. Map the encrypted share. Check backups and shadow copies. Find the entry vector.

## Proof

A scope list and a recovery path with evidence.

## Failure modes

A note can be a decoy. A backup that was mounted can be encrypted too.
