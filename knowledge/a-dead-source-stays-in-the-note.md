# A dead source stays in the note

## Claim

A 404 is evidence of change. Removing it hides the history and the reason for the current state.

## Test

Keep the URL and the archive. Mark the death time. Add the replacement if one exists.

## Proof

A dead URL with an archive and a date.

## Failure modes

An archive can be missing. A redirect can hide the death.
