# Safe harbor is written, not assumed

## Claim

The program terms, the engagement letter and the data handling rules define what you may touch and keep.

## Test

Read the terms. Check the safe harbor and the data clause. Keep the authorization with the report.

## Proof

A scope citation and an authorization path.

## Failure modes

A public bug bounty page is not a contract for every asset. A client letter beats a blog post.
