# Capacity is a model with headroom

## Claim

Arrival rate, service time and headroom predict saturation. A 2x headroom is a starting rule, not a law.

## Test

Measure the service time. Compute the saturation point. Set the headroom.

## Proof

 A capacity model with a clear limit.

## Failure modes

A CPU average hides a queue. A single hot shard sets the limit.
