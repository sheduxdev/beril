# Accessibility is a correctness requirement

## Claim

Keyboard, screen reader, contrast and focus are part of the interface, not a later polish.

## Test

Navigate by keyboard. Check labels and focus. Run an audit.

## Proof

A task completed without a mouse.

## Failure modes

A hidden label is not a label.
