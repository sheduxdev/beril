# Peer review names the weak link, not the style

## Claim

A useful review finds the assumed hop, the missing baseline and the overstated impact. Style comments come after the evidence.

## Test

Read the artifact against the ten axes. Ask one question on the lowest axis and require the evidence before a rewrite.

## Proof

A review note with the weak axis and the test that settles it.

## Failure modes

A review that only edits wording. A reviewer who trusts the tool output. A score with no anchor.
