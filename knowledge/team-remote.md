# Remote work needs explicit overlap and written state

## Claim

The overlap window, the async default and the written update replace the hallway. Time zones bound the window.

## Test

Read the overlap policy. Check a handoff across time zones.

## Proof

A decision made without a synchronous meeting.

## Failure modes

A meeting-only culture excludes a time zone. A silent chat is not a written decision.
