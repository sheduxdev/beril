# Lock-in is the exit cost, not the logo

## Claim

Proprietary APIs, data gravity and contract terms decide the cost to leave. The exit plan is the test.

## Test

Extract a sample dataset. Price the migration. Read the exit clause.

## Proof

A migration and a data export completed.

## Failure modes

An open API is not an exit plan. A discount for a long term is a lock.
