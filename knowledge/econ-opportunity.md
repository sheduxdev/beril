# Opportunity cost is the next best use of the same time

## Claim

The chosen project consumes the capacity of the rejected one. The rejected value is the cost.

## Test

Name the next best option. Compare the expected value of both.

## Proof

A decision that names what was given up.

## Failure modes

A project with no alternative is not free. A sunk cost can hide the next option.
