# A red team report is a defense plan

## Claim

The reader needs the path, the detection gap and the fix. A score without the path is a headline.

## Test

For each step, write the artifact the blue team could have seen and the rule that would catch it.

## Proof

A step table with the artifact and the rule.

## Failure modes

A noisy environment can hide the artifact. A rule can be expensive.
