# An ADR records why, not only what

## Claim

The context, options, decision and consequences survive the people. A stale ADR is superseded, not deleted.

## Test

Write an ADR for one choice. Link the superseded record.

## Proof

A reader can reconstruct the tradeoff.

## Failure modes

A decision log without consequences is a changelog.
