# The space link is a budget

## Claim

The link budget decides the modulation, the coding and the margin. A low margin link is easier to jam or to capture badly.

## Test

Read the link parameters. Measure the signal to noise. Compare with the margin.

## Proof

A measured margin below the plan.

## Failure modes

A clear sky pass can hide it. An adaptive coding can recover.
