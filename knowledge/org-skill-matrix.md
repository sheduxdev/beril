# A skill matrix makes bus factor visible

## Claim

Coverage per system and per skill shows where one person is the only path.

## Test

Build the matrix. Mark primary and backup. Find a row with one primary.

## Proof

A backup for every critical row.

## Failure modes

A matrix that is stale lies. A backup who never practices is not coverage.
