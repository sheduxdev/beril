# Cost is a design constraint

## Claim

Every request, byte and idle resource has a price. A cost budget changes the architecture.

## Test

Measure cost per request. Find the dominant term. Set a budget.

## Proof

A unit cost under the budget.

## Failure modes

A free tier is not an architecture.
