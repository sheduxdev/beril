# Observability answers the next question

## Claim

Logs, metrics and traces should identify the request, the dependency and the failure. A log line without a request id is noise.

## Test

Ask three production questions. Check whether the data answers them. Add the missing field.

## Proof

A trace or query that resolves an incident question.

## Failure modes

High-cardinality labels can cost more than they reveal.
