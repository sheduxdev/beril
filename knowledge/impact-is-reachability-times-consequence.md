# Impact is reachability times consequence

## Claim

The same bug is critical on an internet facing admin and low on an isolated lab. Reachability, actor position and data value move severity more than the class name.

## Test

Name the actor position, the reachable asset and the consequence. Compare two environments before choosing a severity.

## Proof

A severity sentence with actor, path and consequence.

## Failure modes

A CVSS vector with no environment. A theoretical actor. An asset with no data.
