# An intel report separates fact, inference and recommendation

## Claim

A reader must see which sentence came from a source, which is your judgment and which is the proposed action.

## Test

Label each paragraph. Move the inference to a marked block. Name the source per fact.

## Proof

A report where every fact has a source and every judgment is marked.

## Failure modes

A short note can mix the three. A source can be confidential and unlinkable.
