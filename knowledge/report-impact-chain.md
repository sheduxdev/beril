# A report is a chain a triager can rerun

## Claim

The finding needs attacker position, precondition, minimal reproduction, observed result, impact, root cause and fix.

## Test

Write the chain before CVSS. Use the smallest request. Separate confirmed from inferred. List what was not tested.

## Proof

A report another tester can reproduce in five minutes.

## Failure modes

A scanner hit is not a finding. A theoretical chain is not impact.
