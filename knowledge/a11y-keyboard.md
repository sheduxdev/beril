# Keyboard order is the interface for many users

## Claim

Focus order follows the visual order; a trap keeps focus in a widget until escape. Skip links avoid the nav.

## Test

Tab through the page. Check the order, the focus ring and the trap.

## Proof

A complete task without a mouse.

## Failure modes

A custom widget without key handling is a trap. A hidden focus ring blocks orientation.
