# An OSINT lead needs two source classes

## Claim

Two pages on the same site repeat one source. Two classes, such as a registry and a certificate, corroborate.

## Test

Name the source class of each fact. Replace one with a class from the other column. Keep the fact only when both agree.

## Proof

Two independent classes and a date per fact.

## Failure modes

An aggregator can quote the same registry. A primary record can be stale.
