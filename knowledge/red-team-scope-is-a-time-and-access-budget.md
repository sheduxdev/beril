# Red team scope is a time and access budget

## Claim

An open scope without a time box, an access path or a stop condition turns into a pentest with a red team label.

## Test

Write the goal, the start position, the window and the blue team knowledge. Remove any objective without a proof.

## Proof

A one page scope with a start state and an end state.

## Failure modes

A goal can change mid engagement. A hidden test needs a cover story.
