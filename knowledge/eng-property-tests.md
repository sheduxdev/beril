# Property tests find the input you did not imagine

## Claim

A property states an invariant for all inputs. A generator explores the edge cases.

## Test

Write one invariant. Generate inputs. Shrink the failure.

## Proof

A minimal counterexample.

## Failure modes

A property that restates the implementation is circular.
