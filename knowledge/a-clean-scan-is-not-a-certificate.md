# A clean scan is not a certificate

## Claim

A scanner covers a named set of checks. A clean pass says those checks found nothing. It does not say the app is safe.

## Test

Read the checked and not checked lists. Name one untested class that matches the stack. Do one manual request for it.

## Proof

A report with both lists and one manual check outside the scanner set.

## Failure modes

A scope too narrow to matter. A scanner that silently failed. A target behind a login.
