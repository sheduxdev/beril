# A false flag is a deliberate inconsistency

## Claim

An actor can reuse another actor's tool or language string. The inconsistency is in the build, the time or the infrastructure.

## Test

Check the compiler, the timestamps, the code style and the hosting. Compare with the actor baseline.

## Proof

A mismatch between the claimed actor and the build detail.

## Failure modes

A shared tool can be a real reuse. A copy can be perfect.
