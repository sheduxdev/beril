# An actor profile names the constraint

## Claim

A profile without a target class, a budget and a constraint is a logo. The constraint predicts the next move.

## Test

Write the goal, the access, the budget and the risk tolerance. Name one behavior the constraint explains.

## Proof

A prediction tied to a constraint and a source.

## Failure modes

A profile can be a cluster, not a team. A public report can be a plant.
