# Build versus buy compares maintenance, not license

## Claim

The buy price is visible; the build cost includes people, on-call, upgrades and the feature you will miss.

## Test

Write the three-year total for both. Include the team time and the exit.

## Proof

A total cost comparison with a clear delta.

## Failure modes

A build that ignores on-call is a discount illusion. A buy that ignores lock-in is a trap.
