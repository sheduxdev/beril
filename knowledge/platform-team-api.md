# An internal platform is a product with an API and an SLA

## Claim

The team publishes a contract, a support path and a deprecation policy. A ticket queue is not a product.

## Test

Read the internal docs. Try to onboard without asking. Measure the time to first deploy.

## Proof

A team onboarded from the docs.

## Failure modes

A platform with no support path is a gate. A version without a deprecation date is a trap.
